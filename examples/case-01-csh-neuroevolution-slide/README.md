# Case 01 — C-S-H Neuroevolution Academic Slide

This case demonstrates the reconstruction of a flattened academic presentation
slide as layered, editable PowerPoint content.

## Original Flattened Slide

The source is a single 16:9 raster image. Titles, citation text, keywords,
scientific diagrams, institutional branding, background artwork, and layout are
all fused into the same image.

![Original flattened slide](original-slide.png)

## Editable PowerPoint Result

The result is shown inside PowerPoint with multiple objects selected. The visible
selection outlines, resize handles, and rotation handles intentionally demonstrate
that the slide has been reconstructed as separately editable objects instead of
being delivered as one full-slide screenshot.

![Editable PowerPoint object view](editable-powerpoint-view.png)

## Reconstruction Highlights

- Recreate the Chinese title, English paper title, citation, DOI, and keywords as
  editable text objects.
- Preserve the purple academic visual identity and source hierarchy.
- Keep dense scientific artwork as high-fidelity visual elements when a native
  redraw would reduce accuracy.
- Rebuild the slide as layered PowerPoint content with independently selectable
  objects.
- Preserve the source composition without claiming recovery of the original
  vectors, fonts, chart data, or hidden object structure.
