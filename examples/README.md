# Examples

These examples show how flattened slide images can be reconstructed as layered,
editable PowerPoint content while preserving the visual character of the source.

| Case | Source | Demonstration |
|---|---|---|
| [01 — C-S-H neuroevolution academic slide](case-01-csh-neuroevolution-slide/) | Flattened 16:9 slide image | Editable PowerPoint object view with independently selectable elements |
| [02 — C-S-H three challenges academic slide](case-02-csh-three-challenges-slide/) | Flattened 16:9 slide image | Editable PowerPoint object view with independently selectable text, shapes, icons, and scientific visuals |

The example images are presentation artifacts, not part of the installed Codex
skill. Trademarks, institutional marks, publication text, and scientific figures
visible in the examples remain the property of their respective owners.
